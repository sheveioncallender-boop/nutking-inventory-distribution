# Nut King v0.5.3 — Native Routing & Status Display

- Shows Source Location and Destination Location on every Nut King backend transfer.
- Uses the real Odoo operation type, source and destination selected by each quick action.
- Displays one consistent native status bar: Draft → Waiting → Ready → Done.
- Keeps Odoo's real stock.picking states and reservation logic; no custom transfer status was introduced.
- Makes Nut King operation-type defaults updateable during module upgrades.
- Retains all v0.5.2 customer/truck search, product linking and offline hybrid features.
